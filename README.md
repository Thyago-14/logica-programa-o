# Projeto_Calculadora

## Instruções de como fazer a alteração de permissões e execução da calculadora

1- Para alterar a permissão utilizar o comando: chmod 744 projeto_calculadora.sh

2- Para executar o projeto_calculadora.sh utilize comando ./projeto_calculadora.sh

## Como funciona o projeto_calculadora.sh

1- Digite um numero

2- Digite um segundo numero

3- Digite um dos 4 operadores matemáticos disponíveis nesta calculadora (+,-,*,/) caso tente outro operador diferente desses apresentador ocasionará um erro na operação

4- Após a realização das 3 etapas anteriores o resultado do calculo será exibido
